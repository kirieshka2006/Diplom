# Краткий План Действий

1. Оборудование комнат.
- Уйти от ручного ввода оборудования через `Enter`.
- Сделать выбор оборудования через нормальный UI: чекбоксы, теги или список с выбором.
- Продумать отдельную страницу/раздел для управления справочником оборудования.
- Привязать доступное оборудование к категориям комнат, чтобы набор был не универсальным для всех.

2. Очистка Docker и сервера.
- Почистить старые Docker-образы, временные контейнеры, build cache и лишние артефакты.
- Отдельно пройтись по свободному месту на Ubuntu.
- Не трогать боевые данные `GlusterFS`, `media`, `static` и нужные backup-файлы.

3. Админ-панель пользователей.
- Разобраться, кого админ реально может удалять, а кого нет.
- Зафиксировать, что админ должен видеть по пользователю и какие действия доступны.
- Отдельно продумать ограничения по ролям `admin / manager / user`.

4. Страница офисов.
- Сделать страницу офисов более полноценной и информативной.
- Добавить больше полезной информации по каждому офису.
- Потом отдельно решить, какой набор данных и управления должен быть доступен администратору.

5. FAQ.
- Сделать нормальное управление через сайт.
- Администратор должен иметь возможность добавлять, изменять и удалять FAQ-записи.

6. Правила и инструкции.
- Сделать такой же CRUD через сайт.
- Администратор должен иметь возможность добавлять, редактировать и удалять эти блоки без правок кода.

7. Оплата и связь с бронированиями.
- Продумать фейковую оплату/перевод как первый этап.
- Связать оплату со статусами бронирования и общей логикой заявок.
- Понять, какие сущности и статусы придётся менять в моделях и view.
- Это самый крупный и рискованный блок, его делать отдельно и поэтапно.

8. Вернуться к общему редизайну после функционала.
- После стабилизации ключевых функций снова вернуться к общему обновлению дизайна.
- Двигаться поэтапно: страницы, карточки, кнопки, админские экраны.

9. Галерея фотографий комнаты.
- Сделать автоматическую смену фотографий через таймер.
- Не ломать ручное переключение стрелками и миниатюрами.
- Продумать, должен ли автопереключатель ставиться на паузу после ручного выбора фото пользователем.
